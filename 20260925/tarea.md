# Lo que aprendí hoy

Hoy aprendí que **Markdown** permite dar formato al texto de una manera sencilla.

Aprendí a utilizar:

- Títulos con el símbolo `#`.
- **Negrita** escribiendo dos asteriscos a cada lado del texto.
- *Cursiva* escribiendo un asterisco a cada lado del texto.
- Tablas para organizar información.
- Imágenes mediante enlaces.

También aprendí que la sintaxis depende del tipo de archivo:

- En un archivo `.md` funcionan las etiquetas de Markdown.
- En un archivo `.html` funcionan las etiquetas HTML, como `<strong>`.
- En un archivo `.txt` no se interpreta el formato: el texto aparece tal como se escribe.
